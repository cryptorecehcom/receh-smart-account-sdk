# @receh/smart-account-sdk

> SDK TypeScript untuk integrasi RECEH Smart Account di Riche Chain. Gas fee pakai RECEH, berbasis EIP-4337.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.6-blue.svg)](https://www.typescriptlang.org/)
[![Ethers](https://img.shields.io/badge/ethers-6.x-purple.svg)](https://docs.ethers.org/v6/)

---

## ✨ Fitur

- 🚀 Gas pakai RECEH — tidak perlu coin native RIC
- 🔐 Tanpa private key baru — pakai wallet EOA sebagai owner
- 📦 Smart Account di-deploy sebagai Smart Contract
- ⚡ Berbasis EIP-4337 (Account Abstraction)
- 👛 "Wallet di dalam wallet" — dikendalikan EOA
- 🎯 TypeScript-first, framework-agnostic

---

## 📦 Instalasi

```bash
npm install @receh/smart-account-sdk ethers
